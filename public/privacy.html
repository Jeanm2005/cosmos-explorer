Privacy Policy

Cosmos Explorer · Last updated June 2026

Cosmos Explorer is a personal, non-commercial project for exploring public astronomical data. This policy explains what limited data the application processes and why. It is written to reflect what the application actually does, and nothing more.

What this application does not do

  • It does not require you to create an account or provide any personal information.
  • It does not use advertising or analytics tracking cookies.
  • It does not sell, share, or monetize any data.
  • It does not build user profiles or track you across other websites.

What is processed, and why

IP addresses (for security). To protect the service from abuse, the application applies rate limiting to its API endpoints. This requires temporarily processing the IP address of incoming requests to count how many requests each source makes within a short time window. Rate-limit counts for the API proxies are stored transiently in a hosted Redis instance (Upstash) and expire automatically; the machine-learning prediction service counts requests in memory only. IP addresses are used solely for this security purpose and are not used to identify you.

Standard request data. Like any website, the hosting providers (Vercel and Render) automatically log standard technical request information (such as IP address, timestamp, and request path) for operational and security purposes. This is handled by those providers under their own privacy policies.

Third-party services

The application retrieves astronomical data from public third-party APIs. When you use a feature, your browser or the application's servers may contact:

  • NASA (asteroid, exoplanet, and image data)
  • CDS Strasbourg — SIMBAD and VizieR (star and deep-sky catalog data)
  • ESA Gaia archive (used to build the application's datasets)
  • Vercel and Render (application and model hosting)
  • Upstash (transient rate-limit storage)

These services receive only the technical information necessary to fulfill a request and are governed by their own privacy policies.

Cookies

The application does not set tracking or advertising cookies. Any storage used is limited to what is technically necessary for the application to function.

Your rights

Because the application does not collect or retain personal information beyond the transient, security-purpose processing described above, there is no personal account or profile to access, correct, or delete. If you have a question about this policy, you may contact the maintainer through the project's GitHub repository.

Changes

If the application's data practices change (for example, if analytics are added in the future), this policy will be updated to reflect that, and a cookie consent mechanism will be added if required.
